# Accessibility checklist

- Native controls expose button/text input roles, labels, and selected/checked states.
- Status notices include a plain-language heading and message, not color alone.
- Interactive controls meet 44px minimum height; primary actions are 56px.
- Body text is 16px IBM Plex Sans and follows native font scaling.
- Screens scroll; forms keep taps while keyboard is open.
- Urgent messages use danger panel and explicit wording.
- TalkBack, font scaling, contrast, keyboard occlusion, and compact Android layouts still require device verification.
