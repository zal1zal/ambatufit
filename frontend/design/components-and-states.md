# Components and states

Native components: PrimaryButton (default/loading/disabled/pressed), SecondaryButton, TextField (idle/focus/error/password/multiline), EvidenceInput (metadata-driven/selected/error), SafetyNotice (urgent/review), ServiceStatusNotice (available/unavailable/not_configured), ScreenState, GuidanceCard, ProfessionalCard, ProviderAttribution, and ConsentToggle (unchecked by default). Tokens define the 56px primary action, 17px action text, 16px body, 14px labels, 6/10/16 radii, and spacing.

The Figma handoff contains SVG tab/next assets, but the connected file export did not provide the binary files in the repository. Tab icons currently use text glyph fallbacks; export and replace before visual acceptance.
